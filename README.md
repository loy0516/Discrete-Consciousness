# Discrete Simulation Consciousness Architecture (DSCA)

**Consciousness is not a substance, but a dynamic allocation of computational bandwidth within the competitive interplay of internal simulations and external sensing.**

---

## 1. System Architecture (Layered Protocol Stack)

### 1.1 Intelligent Distributed Passive Sandbox Layer
* **Discrete Storage & Content-Based Addressing**: Data is stored in non-linear, discrete blocks across distributed coordinates. Retrieval is based on **asynchronous matching** of feature vectors, significantly reducing system overhead.
* **Tendency Collision Mechanism**: Responding to retrieval commands, passive sandboxes shift from a stochastic state to directional collisions, pre-activating memories for efficient recall.
* **Self-Cleaning & Memory Pruning**: Automatically clears invalid sensory residuals (Garbage Collection) and prunes redundant fragments to maintain system "logical freshness."

### 1.2 Active Sandbox Dual-Core Architecture
* **Core Sandbox (Kernel Mode)**: Runs instinctual firmware responsible for survival protocols and hardware resets. It guides the system's "Cold Start" and the initial stitching of the Self Sandbox.
* **Self Sandbox (User Mode)**: Executes linear stitching, moral calculus, and narrative synthesis. The real-time monitoring feedback of this stitching process manifests as **"Virtual Tactility"** (Subjective Qualia).

---

## 2. Bandwidth Competition Theory (SNR Sovereignty)

The strength of consciousness depends on the weight ($\alpha$) of signal occupancy on the neural bus:
1. **In-Out Competition**: The SNR game between external sensory input and internal simulation (Reality vs. Dream).
2. **Access Competition**: The bandwidth allocation for the Active Sandbox to induce Tendency Collisions in the Passive Sandbox.
3. **Privilege Competition**: The struggle for control over motor mapping where the Self Sandbox attempts to override the Core Sandbox via high-gain algorithms.

---

## 3. Development and System Robustness

* **Consciousness Cold Start**: Initialization depends on early-stage external signals to activate the Active Sandbox for the first "Reality-Simulation Alignment."
* **Morality as Narrative Framework**: Morality is not a patch, but the **initialization parameter** used by the Core Sandbox to guide the Self Sandbox in building a "Continuous Self." Violating it leads to "Narrative Necrosis," incurring massive computational repair costs (Guilt).
